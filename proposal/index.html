01 / LEARN BY DOING

A few lines.
A concrete starting point.

Start with polynomial algebra, then explore stability, robust H∞ and H₂ analysis, and H∞ state-feedback control. All six examples include downloadable MATLAB scripts.

WHAT TO EXPECT

A degree-one polynomial with three 2 × 2 matrix coefficients. Retrieve the coefficient of α₂ using its exponent vector.

Expected result[2 1; 1 3]

About the norms: MATLAB reference ↗

Requires MATLAB, ROLMIP and YALMIP. No solver is needed for this example.

polynomial_example.m
% A homogeneous matrix polynomial on the unit simplex.
% Requires ROLMIP and YALMIP on the MATLAB path.
A1 = [1 0; 0 2];
A2 = [2 1; 1 3];
A3 = [3 0; 0 1];

% A(alpha) = alpha(1)*A1 + alpha(2)*A2 + alpha(3)*A3
% alpha(i) >= 0, sum(alpha) = 1.
A = rolmipvar([A1 A2 A3], 'A', 3, 1);

% Retrieve the coefficient of alpha(2).
coefficient = A([0 1 0]);
disp(coefficient{1});

02 / SET UP YOUR WORKSPACE

Easy to install in
MATLAB.

ROLMIP handles the polynomial structure. YALMIP models the optimization problem. An SDP solver computes the solution.

Download ROLMIP 3.3 ↓
  1. 1

    Install the dependencies

    Install YALMIP. To solve the stability and norm-bound examples, also install SeDuMi and add both to your MATLAB path.

  2. 2

    Add ROLMIP to your path

    Extract the release and point MATLAB to its rolmip folder. Replace the path below with your installation directory.

    addpath('/your/path/rolmip-3.3/rolmip');
savepath;
  3. 3

    Run your first example

    Download a script above and run it in MATLAB. Then explore the manual for multiple simplices, parameter-dependent variables and LMI export.
